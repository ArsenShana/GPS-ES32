GPS-ESP32-E32 — плата-носитель R0, 100 × 78 мм, 2 слоя, FR4 1.6 мм.

Открыть GPS-ESP32-E32.kicad_pro в KiCad. Рядом находятся редактируемая
схема .kicad_sch, разведённая плата .kicad_pcb, локальные библиотеки,
PDF схемы и платы, BOM.csv и отчёты DRC/ERC.

Модули: ESP32-DevKitC V4 WROOM, 38 контактов (19 на сторону,
25.4 мм между рядами); NEO-6M breakout; E32-433T30D.
J2/J3 — гнёзда ESP32, J4 — GPS, J5 — E32, J1 — вход 5 В.
GPS J4: 1=3V3, 2=RX, 3=TX, 4=GND.
E32 J5: 1=M0, 2=M1, 3=RXD, 4=TXD, 5=AUX, 6=5V, 7=GND.

Точная разводка GPIO:
GPS TX -> GPIO16, GPS RX <- GPIO17.
E32 TXD -> GPIO26, E32 RXD <- GPIO27.
E32 M0 <- GPIO25, E32 M1 <- GPIO18, E32 AUX -> GPIO19.
Индикатор: GPIO2 -> R1 330 Ом -> анод D1; катод D1 -> GND.

Прошивка из gps_tracker:
  pio run -e kicad_r0 -t upload
Для демонстрационных координат:
  pio run -e kicad_r0_fake -t upload
Обычные tracker/carrier имеют другую распиновку и не подходят этой разводке.

Питание: внешний стабилизированный источник 5 В / 2 А на J1.
E32 питается от 5 В, GPS — от 3.3 В ESP32. C1 1000 мкФ / 10 В
и C2 100 нФ установлены на шине 5 В возле радио.
JP1 соединяет внешний источник с 5V ESP32: снять перемычку до
подключения USB ESP32. Не подавать автомобильные 12/24 В напрямую.
Перед включением радио подключить подходящую антенну 433 МГц.

Проверено KiCad 10.0.6: DRC — 0 нарушений, 0 неподключённых;
ERC — 0 нарушений. Символы описывают пассивные контакты разъёмов:
ERC не проверяет внутренние цепи модулей и совместимость уровней.
Статус: прототип. До изготовления сверить габариты и порядок контактов
реальных модулей, гнёзда E32, полярность LED и конденсатора, проверить
питание и работу на стенде. Геометрия SMD-площадок упрощена.
Герберы для производства не выпускались.

Повторный экспорт проекта:
  python3 tracker-lab/tools/export_kicad_project.py
PDF и DRC/ERC обновляются отдельно через kicad-cli.
